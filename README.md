# 冠轴运行中心 · WCA Engineering Console

世界儿童协会 **中央办公厅工程与运维局（EOB）** 的对外运行看板，覆盖两处重大基础设施：

- **世界之轴（Axis Mundi）** — 轨道电梯，总长约 40,000 km
- **世界树之冠（World Tree Crown）** — 同步轨道总部空间站

风格为 **深空工业控制台**（石墨底 + 青色数据 + 琥珀警示），与主站的翡翠神话风刻意区分。

## 页面

| 路由 | 页面 | 内容 |
|---|---|---|
| `#/` | 总览 | 今日上下行、在途舱、总功耗、双资产状态、实时事件 |
| `#/axis` | 世界之轴 | 全段剖面（0–39,986 km）、8 节点、在途攀爬舱、张力/温度 |
| `#/crown` | 世界树之冠 | 五环剖视、能源、生保、人口构成、EIOS |

| `#/events` | 事件与告警 | 当值事件流 |
| `#/about` | 关于 | 机构、数据口径、引用文件、声明 |

## 本地运行

```bash
npm start            # http://127.0.0.1:8899
# 或
python3 -m http.server 8899
```

`dev-server.mjs` 同时提供 `/api/telemetry`，与 EdgeOne Function 行为一致。

## 跨终端一致

- `functions/api/telemetry.js` 只返回服务器时间与「2051 时钟」，不返回数据；
- 模拟内核 `js/sim.js` 在客户端运行，输入是统一后的时间戳；
- 因此同一时刻所有终端得到**完全相同**的一组数值，无需数据库或 WebSocket；
- 每秒本地插值，表格与图表每 15 秒重建；每 5 分钟重新授时一次。

## 部署

EdgeOne Pages / Cloudflare Pages：输出目录为仓库根目录，无需构建；`functions/` 由平台识别为边缘函数。若平台按构建产物识别函数，把 `functions/` 一并复制到输出目录即可。
